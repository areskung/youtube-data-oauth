Privacy Policy

Last updated: 2026-11-03

youtube data app is a personal tool used by the operator to download YouTube Analytics and YouTube Reporting data for channels the operator owns or manages.

Data we access

  • YouTube channel identity and basic channel metadata (read-only)
  • YouTube Analytics metrics such as views, watch time, and subscribers (read-only)
  • YouTube Reporting reach and traffic reports when available (read-only)

How we use Google user data

Data is used only to generate internal daily performance summaries for the operator’s own channels. We do not sell Google user data. We do not use Google user data for advertising. We do not transfer Google user data to unrelated third parties except as required to run Google’s own APIs.

Storage

OAuth tokens and downloaded reports are stored on the operator’s private systems with restricted file permissions. Tokens can be revoked at any time in the Google Account permissions page.
